# Kenny Yao · Personal Notes

一个内容优先的个人博客，使用原生 HTML、CSS 和 JavaScript 构建，通过 GitHub Pages 自动部署。

## 本地预览

直接打开 `index.html` 即可预览。发布后，每次推送到 `main` 分支都会触发 GitHub Pages 部署。

## 自定义内容

- 首页身份与简介：编辑 `index.html`
- 文章列表与正文：编辑 `script.js` 中的 `articles`
- 视觉令牌与响应式样式：编辑 `styles.css`
- GitHub Pages 发布：`.github/workflows/deploy.yml`
